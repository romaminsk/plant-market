## Шаблон runbook

1. **Симптомы** — что видит дежурный.
2. **Влияние** — какие сценарии и SLO затронуты.
3. **Диагностика** — команды, метрики, логи, дашборды.
4. **Митигация** — что сделать немедленно.
5. **Откат** — предыдущий образ, forward-only миграция.
6. **Постмортем** — причина, действия, владелец, срок.
