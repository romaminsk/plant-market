## Important — исправлено

- Restock: публичный `GET /restock-subscriptions/{id}` больше не отдаёт e-mail; повторная
  подписка после NOTIFIED сбрасывается в PENDING.
- Media: `spring.servlet.multipart` 10 MB + проверка magic bytes (PNG/JPEG/WebP).
- StockBatch: `adjust` не шлёт restock для QUARANTINE, DEPLETED-партия возвращается в AVAILABLE.
- ShippingZone update больше не реактивирует зону при `active=null`.
- Outbox redrive принимает только `dead=true`.
- Restock помечает подписку NOTIFIED только при успешной отправке письма; при SMTP-сбое
  подписка остаётся PENDING для следующей попытки.
- `POST /api/v1/auth/logout` отзывает refresh-токены пользователя; BFF logout вызывает его.
- `GlobalExceptionHandler` отдаёт 400 для missing header и превышения multipart, а не 500.
- Checkout: `@Valid` на `CheckoutRequest`; BFF требует `shippingZoneId` и `deliveryAddress`,
  отменяет заказ при ошибке checkout/pay, возвращает серверный `totalMinor`.
- Checkout UI: блокирует оплату без термоупаковки для зимней зоны; отдельный E2E J3.
- JSON-LD экранируется (`safeJsonLd`), закрыт `</script>` breakout.
- Order history: обработка network/5xx и частичного отказа history.
- `robots.txt` закрывает cart/checkout/account/api; layout-метаданные `noindex`.
- CSP/X-Frame/Referrer/Permissions для storefront (Next headers) и admin (Vite headers).
- Cart: валидация localStorage (тип, id, цена, количество).
- Demo: seed IP-006 QUARANTINE, `demo-up` запускает seed, reset/up/down/claim скрипты,
  storefront demo на 3100 (auth redirect зарегистрирован).
- E2E: общий кэш seed-данных, тестовые лимиты 600/60, проверка остатка после cancel,
  AdminGallery сохраняет и проверяет URL, J3 UI.
