# ADR-0003: Object storage (MinIO) в Phase 0

- **Статус:** Superseded by ADR-0017 (SeaweedFS для staging)
- **Дата:** 2026-11-05
- **Решающие:** владелец проекта, AI-лид
- **Связанные документы:** `MASTER_PROMPT.md` A7, C1 Task 0.3; `docs/architecture.md`

## Контекст

Конституция и Task 0.3 требуют MinIO как локальное S3-хранилище (порты 9100/9101). При проверке 2026-11-05 выяснилось:

- Официальный образ `minio/minio` на Docker Hub больше не существует: `docker pull minio/minio:latest` → `pull access denied ... repository does not exist`.
- `quay.io/minio/minio` отдаёт `401` на анонимный запрос манифеста.
- В GitHub issue minio/minio#21647 maintainer подтвердил: с октября 2025 проект распространяется **только исходниками**, официальные Docker-образы больше не публикуются; репозиторий архивирован 25 апреля 2026.
- Последний публичный релиз — `RELEASE.2025-10-15T17-29-55Z` (в нём исправлена CVE); новых официальных образов и патчей не будет.

Это несовместимость с целевым стеком A8: версию/образ, которой больше нет, нельзя считать проверенной и поддерживаемой.

## Варианты

| #   | Вариант                                                                             | Плюсы                                                 | Минусы                                                                                   |
| --- | ----------------------------------------------------------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| A   | Community-образ `coollabsio/minio:RELEASE.2025-10-15T17-29-55Z` (Docker Hub / GHCR) | Работает сразу, тот же API, pin на конкретный релиз   | Не official; нет гарантии обновлений и безопасности; только dev                          |
| B   | Собрать MinIO из исходников в своём Dockerfile (multi-stage Go)                     | Воспроизводимо, без чужого образа                     | Сборка тяжёлая для 4 ГБ Colima; исходники архивированы, патчей нет; сопровождение на нас |
| C   | Заменить на активно поддерживаемый S3-совместимый сервис (Garage, SeaweedFS)        | Живой проект, легче, есть S3 API                      | Отход от целевого стека A7; нужен новый ADR и проверка API media-service                 |
| D   | Отложить object storage до Phase 3; в Phase 0 — локальная файловая заглушка         | Не блокирует Phase 0; media-service всё равно Phase 3 | Task 0.3 выполняется без MinIO; compose отличается от мастер-промта                      |

## Решение

Владелец проекта выбрал **вариант D**: в Phase 0 object storage не используется; MinIO и выбор S3-совместимого хранилища откладываются до Phase 3, когда появляется media-service. `docker-compose.yml` Phase 0 не содержит MinIO.

## Последствия

- `docker-compose.yml` Phase 0 не содержит MinIO; порты 9100/9101 остаются зарезервированными.
- Перед Phase 3 нужен новый ADR: замена MinIO на поддерживаемый S3-совместимый сервис (Garage, SeaweedFS) или собственное сопровождение образа.
- `media-service` и загрузка изображений не входят в Phase 0.
- Факт «MinIO official images discontinued» зафиксирован здесь и в `docs/status.md`.

## Проверка

- `grep -i minio docker-compose.yml` не даёт совпадений.
- Отдельный ADR с датой и источником решения создаётся до начала Phase 3.
